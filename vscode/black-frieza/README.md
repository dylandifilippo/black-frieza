# Black Frieza

A balanced dark theme — neither too light nor too dark, built to work day and night. Saturated syntax colors, a terminal that matches the sidebar, and matte khaki-and-violet accents.

Two variants: **Black Frieza** (softer gray chrome) and **Black Frieza Darker** (near-black chrome). Select via `cmd-k cmd-t`.

Based on [New Darcula](https://github.com/e-simpson/new-darcula-z) by Evan Simpson. Also available [for Zed](https://github.com/dylandifilippo/black-frieza).

Full palette and screenshots: [github.com/dylandifilippo/black-frieza](https://github.com/dylandifilippo/black-frieza)
